# Rasch 题项分析与跨语种等值口径

`analyze` 在现有答对率清点（`summary`，保留不变）之外提供二元 Rasch 分析：把参与者能力与题目难度分离开，检查两个语言版本能否等值，并产出题项复核清单。`score` 用已发布的模型档案给新批次评分。所有输出只用于题项复核与能力描述，**不构成人员淘汰或分班决定**。

## 模型与缺答

- 二元 Rasch 模型：P(答对) = logistic(θ_p − b)，θ_p 为参与者能力，b 为题目难度。
- `answered=false` 的记录不进入似然，缺答不算答错；其 `correct` 仅为存储占位。
- `answered=true` 时 `correct` 必须为 0 或 1；同一参与者对同一题目的重复已答记录、同一参与者跨语言版本，都会被拒绝。
- 锚题在两个语言间共享一个难度参数，把两个版本连接到同一把尺上；非锚题按 题目×语言 分别估计难度。

## 估计方法与位置约束

- 题目难度用**条件极大似然（CML）**估计：对每人总分条件化，从似然中消去能力参数。短卷下联合极大似然（JML）的难度估计有系统性偏差，会让锚题检验在零假设下也显著，因此不采用。
- 能力在难度给定后用普通极大似然估计（逐人牛顿法）。
- 位置约束：每轮迭代后强制**锚题难度均值为 0**，全部参数同步平移。档案 `parameters.constraint` 记录该约定。
- 协方差取约束下信息矩阵的伪逆 I⁺ = (I + uuᵀ)⁻¹ − uuᵀ（u 为平移方向），DIF 对比的方差含两单元格的协方差项。

## 极端全对/全错的处理

- 全对或全错的参与者、全对或全错的题目×语言单元格，其似然在参数无界处达到最大，没有有限估计。
- 估计前迭代剔除这些参与者与单元格，逐条记录在档案 `diagnostics.excludedPersons / excludedCells`。
- 剔除后**重新检查**参与者—题项图连通性与锚题覆盖：原始设计连通不代表剔除后仍连通。
- 评分时全对/全错的参与者 `theta` 记为 `null` 并标注 `extreme`，不编造数值。

## 连接检查与锚题覆盖

- 先检查参与者—题项二部图：多个连通分量 → `equating.status = disconnected`，不出具参数。
- 锚题须至少在两种语言有已答覆盖，否则 `anchors-not-covering`。
- 断开的版本不能声称已经等值：报告中 `equating.status` 明确标注（含 `stage: design/estimable` 区分断连发生在原始设计还是剔除极端分之后），`parameters` 为 `null`。

## 语言 DIF 检验

- 联合拟合后，非锚题的语种偏移 Δ = b_其他语种 − b_参考语种（`policy.referenceLanguage` 为参考）。
- Wald 检验，标准误来自约束下完整协方差矩阵；同一批题项统一做 Benjamini–Hochberg 校正，报告 q 值。
- 每个检验报告：效应量 Δ（logits）、95% 置信区间、各语种单元格的样本量与标准误（`support`）、ETS A/B/C 分级（|Δ| < 0.43 / 0.43–0.64 / > 0.64）。不只用显著性星号做判断。
- 单元格缺失或极端导致无法检验的题项列入 `dif.untestable` 并进入复核清单。

## 锚题净化（预先给定的迭代规则）

锚题也可能有偏。净化规则预先设定，不随数据调整：

1. 每轮把当前锚集中每个锚题单独释放，以**其余锚题 + 全部未移除题项**的共识为连接重新联合拟合（只用其余锚题作连接时，两个锚题会精确互相混叠，无法分辨谁有偏）。
2. 轮内对全部 锚题×语种 检验做 BH 校正，`q < alpha` 的锚题本轮全部移除，移除原因（统计量、q 值、轮次）逐条记录。
3. 被移除的锚题退出后续轮次的链接池；最多 `maxPurification` 轮（`policy.json`）。
4. 终止状态：`stable`（整轮无移除）、`too-few-to-test`（剩余锚题不足两个，无法继续检验）、`round-limit-reached`（达到预设轮次上限仍有移除，剩余锚题按存疑处理）、`anchors-exhausted`（锚集耗尽，不得声称等值，不出具参数）。

**不能根据同一数据反复挑到"没有偏差"为止再当确认性结论**：只要净化移除过锚题，报告 `inference` 即为 `exploratory` 并在 `notes` 中声明结果属探索性、不能当作确认性结论；未发生移除时为 `confirmatory`。如需确认性结论，应用独立数据复核。

## 模型档案

`analyze --out` 写出的档案包含：

- `items`：题目版本登记（校准输入须与 `policy.frozenVersion` 一致，否则直接拒绝）；
- `anchors`：配置锚集、最终锚集、被移除锚题及每轮原因；
- `parameters`：难度与位置约束（含各参数标准误）；**不含校准样本的能力**，人员能力由 `score` 按需生成；
- `diagnostics`：估计方法、迭代次数、收敛标志、条件对数似然、剔除清单；
- `equating`、`purification`、`dif`、`reviewList`、`inference`、`inputFingerprint`、`policyFingerprint`。

## 冻结评分

- `score --model 档案` 只读档案：难度不重新估计，档案文件不被修改（测试逐字节核对）。
- 新批次逐条记录与档案题目版本核对：未知题（`unknown-item`）、版本不符（`version-mismatch`）、无对应语种难度（`no-difficulty-for-language`）的作答被排除并在输出中列明，不悄悄改用其他难度。
- 缺答不参与评分；全对/全错者 `theta` 为 `null` 并标注。

## 局限

- Wald 检验为正态近似；小样本单元格的检验功效低，请看效应量与样本支持而非只看显著性。
- 锚题净化的链接池包含非锚题；若非锚题存在很大的真实偏移，链接会被稀释性污染，可能误伤干净锚题——此时结论降级为探索性并进入复核清单，由人工复核。
- 能力估计在短卷下测量误差较大，极端分参与者无法给出有限能力值。
